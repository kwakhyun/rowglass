# Third-party notices

## Lucide icons

Rowglass bundles ten SVG icons from the official [Lucide repository](https://github.com/lucide-icons/lucide). The SVG geometry is copied unchanged. The wrapper adds configurable dimensions, a CSS class, and decorative accessibility attributes.

Lucide uses the ISC License. Its upstream license also includes the MIT License for icons derived from Feather. Of this bundled subset, `arrow-right`, `arrow-up-right`, `check`, `chevron-right`, `download`, `plus`, `search`, and `x` appear in that Feather list. Both notices are reproduced below.

Sources were retrieved from the official repository's `main` branch. The Git blob IDs identify the exact fetched contents; they are not release versions or commit IDs.

The bundled module has no package dependency and performs no network requests. It exports `ICON_LICENSE_COMMENT` so generated HTML can carry these notices. Include that constant once in every generated HTML document that contains the icons. The comment changes the upstream separator from `---` to `===` to keep the HTML comment valid; the license terms and copyright notices are unchanged.
