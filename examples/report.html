A small, checkable calculation.

Before + added rows − removed rows + changes to matched values = after. Keys match exactly, including case and whitespace. Duplicate or empty keys and invalid numbers stop the comparison. Decimal totals use integer arithmetic; chart positions are approximate.

Only the selected key columns and metric are included in the saved report. The report contains those values: review them before sharing. Rowglass makes no network requests and does not collect usage data.
